# Start in ChatGPT / 在 ChatGPT 中开始

Upload [IELTS-speaking-workflow.md](IELTS-speaking-workflow.md) and the materials you are entitled to use. Copy the prompt in your preferred language. The bundle contains the workflow and blank templates; no installed skill, custom GPT, or access to a local folder is assumed.

上传 [IELTS-speaking-workflow.md](IELTS-speaking-workflow.md) 及你有权使用的材料，再复制所需语言的提示词。上传文档含工作流与空白模板，不假定已安装技能、自定义 GPT 或能访问电脑文件夹。

## English prompt

```text
Use the uploaded IELTS Speaking Workflow as guidance for my teaching task.

Task: [course planning / lesson design / material organization / slide creation / review / revision / continuation]
Learners and current ability: [provide what is known]
Speaking focus, aim, and duration: [provide what is known]
Materials: [identify the uploaded or pasted sources and permitted adaptations]
Deliverable and audience: [state what you want]
Output language and visual preferences: [state your choices]

Reuse the context already provided. Ask only about missing information that changes the result. Use general CELTA-informed principles where appropriate, without imposing one framework. Check the tools available in this chat. If a PPTX can be created or edited, deliver the actual file and state the checks completed. Otherwise give complete slide content or review recommendations and explicitly say that no PPTX was created or changed. For review-only work, leave the source unchanged. Distinguish official material, adaptations, and AI-authored practice. Do not publish my materials.
```

## 中文提示词

```text
请根据已上传的 IELTS Speaking Workflow，协助完成我的教学任务。

任务类型：[课程规划／课次设计／材料整理／课件制作／审查／修改／续做]
学员及已知水平：[填写已知信息]
口语重点、目标和课时：[填写已知信息]
材料：[注明上传或粘贴的资料及允许的改编范围]
交付物与读者：[说明需要什么]
输出语言和视觉偏好：[说明你的选择]

沿用已提供的上下文，只询问影响结果的缺项。按需采用通用 CELTA 教学原则，不强制单一框架。先检查当前对话中的实际工具：能制作或修改 PPTX 时交付真实文件并说明已完成检查；不能时交付完整逐页内容或审查建议，并明确说明未生成或修改 PPTX。仅审查时保留源文件。区分官方材料、改编和 AI 自编练习，不公开我的材料。
```

## ChatGPT project / ChatGPT 项目

Add the bundle to project sources. Put the following short instruction in the project instructions, then use a separate chat for each distinct teaching task:

将上传文档加入项目来源，在项目指令中加入以下简短说明，再为各项独立教学任务分别开启对话：

```text
For IELTS speaking teaching tasks, use the uploaded IELTS Speaking Workflow. Reuse confirmed context, choose only the requested branch, and distinguish actual file work from text-only planning. Follow the teacher's current brief and requested output language. / 雅思口语教学任务使用已上传工作流，沿用已确认信息，只执行所需分支，区分实际文件操作与纯文本方案，遵从当前教学约定和输出语言。
```

Projects share uploaded files and instructions across their chats; a web project does not automatically access your computer's folders. See [official project guidance](https://learn.chatgpt.com/docs/projects). Availability of file creation and rendering depends on the tools in the current chat.

项目可在对话间共用已上传文件与项目指令；网页项目不会自动获得电脑目录访问权。参见[官方项目说明](https://learn.chatgpt.com/docs/projects)。文件生成与渲染取决于当前对话实际具备的工具。
